Connect Any LLM Provider

DriftGuard is provider-neutral. Record the same four metrics after a Gemini, OpenAI, Anthropic, local, or custom model call.

# 1. Install SDK
pip install driftguard

# 2. Initialize Client
from driftguard import DriftGuardClient

client = DriftGuardClient(
    api_key="your_api_key",
    project_name="antigravity-agent",
    base_url="http://localhost:8000"
)

# 3. Record Metrics & Evaluate Drift
client.capture_metrics(
    prompt_tokens=3950,
    context_length=4850,
    retrieval_score=0.65,
    response_quality=0.82
)

report = client.check_drift()
print(report)

# 4. Ship telemetry to DriftGuard
client.sync_metrics("antigravity-live")
Provider adapter: call your model exactly as usual, then map its usage and quality signals to prompt_tokens, context_length, retrieval_score, and response_quality. DriftGuard never requires or replaces your provider SDK.
